## Riêng cho Claude Code
- Hook trong `.claude/settings.json`: SessionStart nạp PROGRESS + trạng thái autopilot (cả sau compaction); PreCompact ghi checkpoint (`xt.py loop checkpoint`, luôn exit 0); PreToolUse **không hỏi người** (ADR-0018) — nguy hiểm/không đảo ngược thì **chặn**: lệnh phá huỷ/`curl|sh` (cả lồng trong `sh -c`/heredoc; lồng quá 4 lớp và brace expansion `{a,b}` bung ra lệnh cấm cũng chặn), ghi file bí mật (cả qua Bash), gửi file bí mật/biến môi trường ra mạng (curl/wget, `scp`/`rsync` tới máy khác, `nc`/`socat`/`ssh`, `gh gist|release upload`, `/dev/tcp`), push thẳng nhánh chính/`push --all/--tags`, xoá đệ quy ngoài thư mục dự án, `stash drop/clear`, huỷ repo/bí mật/hạ tầng (`gh repo delete|archive`, `gh secret`, `kubectl delete`, `terraform|tofu|pulumi destroy`), container có quyền máy chủ (`--privileged`, namespace host, mount `/`/home/socket), tắt/bỏ qua hook (cả ghi `.git/hooks`/`.git/config`, đặt/bỏ `core.hooksPath`, khoá git chạy lệnh ngầm như `core.fsmonitor`; `--no-verify` vẫn chạy cổng của khung), ghi/xoá tay `.autopilot/` (bằng chứng, trạng thái vòng, sổ review, bytecode hook — chỉ `xt.py` ghi; ADR-0026) và dấu review đăng tay lên PR (`gh pr comment`, `gh api`, tool MCP comment — chỉ `xt.py pr reviewed`; ADR-0027), CLI agent khác với cờ tự duyệt (`codex --full-auto`, `gemini --yolo`, `copilot --allow-all-tools`… — LOOP-STOP-028), commit ghi tên model/URL phiên AI khi `xt.yaml` có `ai_attribution: forbid` (LOOP-HARNESS-027), merge/bật auto-merge PR ngoại lệ cứng (`merge-check` trả `hard` — ADR-0019; repo này `merge_hard_exceptions: auto` nên không còn `hard` — ADR-0020), merge/bật auto-merge PR làn chuẩn chưa có review sạch ở head — mọi dạng merge, ghim head hay không (`gh pr merge`, `gh api …/merge`, tool MCP merge; mã `REVIEW_MISSING`, D-100, AUD-HAR-093 — `merge-check` `eligible`/`auto_merge_ok` false, ADR-0028/0032; pha `delivery_phase: build` hoãn review nên không chặn — ADR-0031); còn lại **cho chạy** kể cả việc trước đây hỏi — deploy/publish, merge PR và bật auto-merge khác (kể cả `gh api` ghi, tool MCP merge — khi `xt.py merge-check` không cho vì lý do ngoài review và ngoại lệ cứng, như CI chưa xanh, xung đột, tụt sau: guard chỉ hỏi ở `strict`, lớp đỡ là CI/ruleset nhánh), sửa cấu hình cổng/CI/hook/migration, làm yếu/xoá test, thêm MCP/plugin/skill, cập nhật snapshot, ra khỏi máy dev (`ssh`, `psql` tới máy khác, `curl` gửi dữ liệu…), thêm phụ thuộc, container trên daemon máy khác; quét cả `eval`, backtick, `{ …; }`, `find -exec/-delete` (cả `-L`, bộ lọc `-path`/`-name` trúng `.autopilot/`, `| xargs`), biến gán bằng chữ (`x='…'; eval "$x"`), `$'…'`, `${IFS}`, `<( )`, lệnh bọc (`flock`, `watch`, `script -c`, `su -c`, `busybox`…), `os.system`/`subprocess` trong script; script trình thông dịch (`python -c`/heredoc, `node -e`, `ruby -e`…) nhắc hàng rào, `.git/hooks`/`.git/config`, bí mật hay `.autopilot/` mà không chỉ gồm thao tác đọc thì chặn (D-105); sau `cd` guard không giải được (biến, `cd -`, `popd`, `CDPATH`) đích ghi tương đối được thử ở mọi thư mục canh (D-106); lệnh Gate/`Kiểm:`/`xt.yaml` do harness chạy (`xt.py`, `dev-task.sh`) cũng qua guard, bị cấm thì không chạy (LOOP-STOP-027); chạy cổng chất lượng trước `git commit` (commit vào repo ngoài dự án: cho qua, không chạy cổng của repo lạ); `XT_GUARD_POLICY=strict` trả lại hành vi hỏi cũ; PostToolUse format file vừa sửa; Stop đọc bằng chứng autopilot (`xt.py loop hook-stop`) để quyết cho dừng hay làm tiếp.
- Quyền: `permissions.allow` gồm `Bash`, `permissions.ask` rỗng — mọi lệnh Bash chạy không hỏi; hàng rào là `deny` của settings và hook guard ở trên (ADR-0017, ADR-0018). `install.py` gộp đúng các quyền này vào `settings.json` đã có của dự án đích (giữ quyền riêng).
- Chế độ quyền chọn theo phiên — `permissions.defaultMode` trong settings dự án **bị Claude Code bỏ qua** với `auto`/`bypassPermissions`. **Phiên cloud** (claude.ai/code, app Claude): chọn chế độ **Auto** ở bộ chọn chế độ quyền khi mở phiên. Phiên CLI cục bộ: `claude --permission-mode auto` hoặc `defaultMode` ở settings người dùng. Autopilot một phiên cần chế độ Auto (Stop hook cảnh báo khi phiên ở `default`/`plan`/`acceptEdits` — phiên sẽ đứng chờ bấm duyệt). Ở Auto, bộ phân loại của Claude Code vẫn có thể chặn thêm (bị chặn là kết luận, AGENTS.md §3); `deny` của settings và guard chặn ở mọi chế độ, kể cả bypass.
- Skill gọi bằng `/autopilot`, `/blueprint`, `/gate`, `/research`, `/audit`, `/review`, `/adr`, `/handover` (định nghĩa ở `.claude/skills/*/SKILL.md`).
- Chạy headless cho CI: **không** dùng `--bare` (mất hook/skill/CLAUDE.md).
